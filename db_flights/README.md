## Deployment Configuration

The bundle does not store workspace-specific information such as the Databricks host or user name.

Before deploying, authenticate with your Databricks workspace:

```bash
databricks auth login
```

The current authenticated user is automatically used for permissions:

```yaml
permissions:
  - user_name: ${workspace.current_user.userName}
    level: CAN_MANAGE
```

Then validate and deploy the bundle:

```bash
databricks bundle validate
databricks bundle deploy
```
